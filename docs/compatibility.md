# 支持矩阵

当前没有已经通过的 Windows/内核组合。源码可读或存在 API 文档，不等于对应用户环境可以直接使用。

| 平台 / 场景 | 规划 | 当前状态 |
|---|---|---|
| Windows x64 + 一个选定 v2rayN 实例 | 首版目标；系统/版本在 S0 冻结 | 未验证 |
| Xray + 普通单节点 | 默认第一内核候选 | 仅固定提交源码核读 |
| sing-box + 普通单节点 | 第二内核候选；可按实际环境调整顺序 | 仅固定提交源码核读 |
| TUN | 只有流量范围和归属通过后才纳入 | 未验证 |
| 策略组 / 多出站 / 代理链 | 不承诺首版最终出口级精确统计 | 延后或明确降级 |
| 多实例、跨设备、云端 | 不在首版范围 | 不支持 |
| TrafficMonitor | S7 可选；冻结 Release 与位数 | 未实现 |

S0 环境记录模板：v2rayN 版本、内核名称/完整版本、Windows 版本/位数、代理模式、发现路径、原始计量单位、API 端口读取来源、流量范围、节点归属级别、测试命令、结果、脱敏证据位置。

接口不可用必须显示“未连接/不支持/需要开启设置”，不能把空响应当作零使用量。估算模式必须全链路标识；严禁将其写成“精确计量已通过”。
