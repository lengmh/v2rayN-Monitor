# 采集明细显示优化

2026-10-12，基线 `14a7ead`，PR #9 内的有界前端显示调整。

- 仅本机采集明细按量级显示 B / KB / MB / GB；选择 GiB 时使用 B / KiB / MiB / GiB。数字格式化全程使用 BigInt，悬停仍显示原始整数 bytes。
- 明细列宽固定时间、下载、上传与质量列，节点名使用剩余宽度并保留完整名称提示；减少单元格内边距。移动端只在表格区域横向滚动。
- 分时近似保留文字和解释，改为低强调标签。部分重叠未计入、恢复未分时、未知归属等原有警示保持。
- 未改变 API、账本、汇总、导出、服务商原始量或精确十进制计费量。
