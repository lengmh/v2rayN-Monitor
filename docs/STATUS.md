### 采集与保存

- 只读发现固定客户端、父子进程、标准配置和回环监听；采样前后复核身份及核心代次。普通单节点按 `instance_id + IndexId` 分账，不按名称合并。
- 首接只建基线，双向检查重置；增量、游标及缺口原子提交。身份不连续时保留未知，连续停机恢复量保存为未分时，不伪造跨日分布。
- 标准多出站与策略组按实际成员独立记账，旧长连接保持原成员；组、成员、业务汇总、直连及探测不重复相加。未知范围不阻断已核实范围。
- 默认本机历史可读取同一账本的跨核心记录；普通历史维度、节点目录、分页和导出使用相同口径。更改当前核心不隐藏旧历史。
- GUI 原样原子保存仅在有界稳定重读的全部字节一致时延续；内容、核心、sidecar、进程及身份保护保持。

### 展示与 CSV

- 原名、策略组标签和可信 key 的展示归并不改变历史身份。固定生成 tag 与已保存名称相互核实时可补齐显示，不按当前名称重算旧倍率或写回历史。
- 原始量为整数 bytes；服务商计费量保留 CSV 精确十进制值。新倍率快照依据节点原名：无标记、1x／1倍为 1，冲突为未知；旧未知不回填，恢复未分时不估算。
- 四种统计视图、同名节点与时间桶配对、精确值弹窗、深浅主题、非零明细、图表下钻、有界首次补查和主动刷新已交付。
- 六列 CSV 支持同文件幂等及约定语义下按规范化行签名／出现次数增量去重，保留合法重复，冲突拒绝整批。无稳定记录 ID 不承诺普适去重。
- 批次 occurrence 引用、撤销预览／token 重验及事务共享保护已交付。旧库仅经显式备份升级启用，旧批次不猜引用；不为验收强制升级真实 provider。
- 原 CSV 归档默认关闭，由浏览器显式另存原 File，保留 BOM；仅写入并关闭成功才报告已保存，取消或失败不回滚导入。

## 性能结论

- 真实副本月／年完整输出对账通过，中位数为 58.25／55.19 ms；首次月查询复用持久汇总为 226.34 ms。这些是原环境的后端测量，后续包不冒称重新测得。
- 独立真实闭页观察为平均 CPU 0.03841%、工作集 148.06–148.35 MiB，前后入站 HTTP 均为 0，达到原资源目标。先前仍有 HTTP 连接的观察不能作为闭页通过依据。
- 全年合成基准为 365 天／3 节点／1,576,800 条分钟及同数展示证据，完整输出、8 组分页、独立公式和单日重算通过。有持久汇总的新进程年首查 498.09 ms，热中位数 108.25 ms；空汇总首查 7677.07 ms，后续构建 135.16 秒，不改称一秒内。
- 适用条件、留存默认值及恢复方式见 [日级历史汇总](proposals/history-summaries.md)。S4.3／G3 已完成，不重复初始化、闭页或全年验收。
