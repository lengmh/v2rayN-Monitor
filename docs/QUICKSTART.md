# v0.1.1 使用说明

> 这是 v0.1.1 的历史操作参考。当前 v0.2.0 已发布，三档包、已支持核心、CSV 新功能及 v1／v2／v3 升级模式请先看 [v0.2.0 发布与升级说明](release-v0.2.0.md)；下文旧版限制不覆盖当前支持矩阵。

本说明对应 v0.1.1 修复版，包含日期默认分桶与重叠 CSV 增量导入；这些新增行为不包含在 v0.1.0 包中。实际发布版本与下载资产以 GitHub Releases 为准。

## 1. 准备

目标：Windows x64，v2rayN 7.25.1，Xray，普通单节点。用户已于 2026-10-12 确认无图标预览版整体验收；未提供新的逐项测试记录，不能据此推断所有场景均已实测。新增图标尚无实机目视确认。升级前保留你的原有数据备份，不用于账单或费用结算。CI 便携包包含 .NET 运行时，不需要管理员权限、驱动、WebView2 或常开浏览器。

运行 `V2rayN-Monitor.exe` 后，会出现托盘图标并打开系统浏览器。关闭网页继续采集；选择托盘“退出并停止采集”才停止程序。重复启动同一 Monitor 数据目录不会产生第二个写入进程。

## 2. 连接 v2rayN

1. 在 v2rayN 中自行确认使用 Xray、普通单节点，并开启流量统计或实时速度显示。Monitor 不会代你修改这些设置或重启核心。设置改变后是否需要重新启动核心，以 v2rayN 界面提示为准。
2. 在 Monitor 设置或托盘“选择 v2rayN 数据目录”中，选择包含 `guiConfigs/guiNConfig.json`、`guiConfigs/guiNDB.db` 和 `binConfigs/config.json` 的根目录。便携安装通常是程序目录；启用 `V2RAYN_LOCAL_APPLICATION_DATA_V2=1` 时可能是 `%LOCALAPPDATA%\v2rayN`。
3. 首次成功读取只建立基线，之前已有累计不会全部算作今天。此后生成的流量按 v2rayN 活动配置写入历史，以实例与 IndexId 分账。连接参数相同的不同 IndexId 不合并，名称仅用于展示；这不是从核心侧独立识别完全相同的逻辑配置。
4. 托盘打开的是短期会话链接。若页面提示会话过期，从托盘重新打开即可；刷新网页不会重复记账。

## 3. 查看与导出

默认使用首次启动时的系统统计时区，可以在设置中更改。数据库一直保存 UTC，改时区只改变分组方式，不改字节量。日看小时、周/月看日、年看月，也可自定义时间范围和分桶粒度。周从周一开始。

本机字节值始终为整数；GB/GiB 只是显示单位。记录为 UTC 分钟汇总，跨分钟短采样按比例分配，属于分时近似。单次导出最多 100000 条记录，超过后缩小范围或选择节点。节点名已处理表格公式前缀。

图表空档、采集缺口与“恢复但未分时”有不同含义。后者仅在同一进程/映射身份仍可确认时恢复总量，不放进日期图表。未知归属不计到新节点。历史不会因为接口离线被覆盖。

## 4. CSV 只是可选补充

表头固定为 `node_name,rate,origin_traffic,origin_x_rate,traffic,log_time`。来源填写服务商/账户标识，时间明确选择时区；无时区时间格式为 `yyyy-MM-dd HH:mm:ss`。无法确定的夏令时重复/跳变时间会拒绝导入。

先预览再确认。原始量为非负整数；倍率与计费量允许精确非负十进制小数。计费量直接保存 CSV 数值，不通过取整、浮点或原始量乘倍率重算。小数使用最多 28 位小数和 96 位十进制系数（最大整数 79228162514264337593543950335），去除无意义的末尾零后检查；每条值及批次总计必须能够无损表示，否则整批拒绝。只接受普通十进制写法，不接受指数、负数、NaN 或 Infinity。预览与批次列表同时显示精确数值；traffic 只是原始显示文本。既有整数服务商数据库在启动时事务迁移，整数值不变；建议升级前按第 6 节备份。旧预览不能无损读取新写入的小数计费量；需要退回旧版时使用升级前备份，不共用已升级的 provider.db。每文件最多 4 MB（UTF-8 编码后 4,000,000 bytes）、50,000 条数据记录，不含表头。同一来源视作重复导出快照，以 UTC 时间、精确节点名、倍率、原始量及精确计费量匹配出现次数，保留文件内合法重复，只导入超过已保存次数的新增部分；traffic 显示文本不参与匹配。预览列出文件记录、新增、跳过和新增精确量，提交时重新核对。全部重复时不新增记录或批次。同时间同名但计费字段变化且无法确认是否修订时提示冲突，不覆盖旧记录。无稳定记录 ID，不能用这种快照约定去识别任意独立账单事件。记录时间最小值和最大值不证明完整覆盖。没有设备、IP、上下行字段时就是未知，不能把差额归给某台设备。

CSV 与本机数据分别存储、分别显示，不相加。初版未提供批次撤销；提交前确认来源和时区。

## 5. 故障排查

- 未配置目录：选择 v2rayN 数据根目录，不能只选 `guiConfigs` 子目录。
- 未启用统计/无 metrics：在 v2rayN 自行开启流量统计或实时速度显示，确认有效配置重新生成；端口是动态的，不要写死端口号。
- 无法核对进程/端口：Monitor 保持普通权限。v2rayN 已提升权限时，会尝试只读补足 WMI 缺失的路径和命令行，并核对创建时间；仍无法核实时暂停归属并保留缺口。不要为此给 Monitor 提权。
- Hysteria2：V2free 7.25.1 的 Xray 配置按 `hysteria` 和 transport auth 识别；需与所选节点及进程代次一致。
- AnyTLS：V2free 7.25.1 为该协议选择 sing-box，当前采集器尚未覆盖。不要为接入 Monitor 擅自切换核心或节点。
- 配置正在切换/基线变化：等待 v2rayN 完成切换。采样前后核对活动项、配置和核心代次。活动 IndexId 改变后先重新建基线，不把旧累计或不确定边界计入新配置；配置与活动项尚未匹配时保留缺口。
- 连接字段尚未覆盖：mKCP、自定义 PEM 证书、自定义 Finalmask、Hysteria Realm URL，以及绑定网卡并使用 XHTTP downloadSettings 的组合显示 `unsupported_connection`，暂停归属。不要为接入 Monitor 擅自改变当前连接参数。
- 不支持模式：关闭 TUN/链/策略组等需由你自己决定。Monitor 不自动更改代理路由。
- 没有流量字段：尚未观察到可验证的计数，不等于零。流量产生后仍未出现时检查 Xray 统计设置。
- 写入失败：检查磁盘空间和 Monitor 数据目录权限。不要删除数据库作为第一步，也不要上传真实库或完整配置排错。
- 页面打不开：确认默认浏览器可用，然后从托盘重开。页面关闭不会影响采集。

## 6. 数据与备份

默认 `%LOCALAPPDATA%\V2rayN-Monitor\data`，演示为同级 `demo`。自定义 Monitor 目录通过 `--data-dir`，与 v2rayN 数据目录是两个不同设置。

退出 Monitor 后备份整个 Monitor 数据目录（包含 history.db、provider.db、settings.json 及可能的 SQLite sidecar）。不要在运行中只复制主数据库文件。不要把数据目录放进公开仓库、共享文件夹或自动上传位置。开机启动由托盘菜单显式开关，只修改当前用户的启动项。

便携包未签名，可能触发 Windows 下载文件提示。自行核对 Releases 页面对应提交、下载资产与 SHA256，不要绕过浏览器证书/安全连接警告。签名尚未提供；用户验收范围及开发验证记录见 docs/STATUS.md。


## 7. v2rayN + Monitor 联动启动（开发预览，未包含在 v0.1.1 正式包）

此功能属于 [Issue #24](https://github.com/lengmh/v2rayN-Monitor/issues/24) 的可选联动入口。已有的“登录 Windows 时启动”不变。

1. 运行开发预览版 Monitor，先选好 v2rayN **数据目录**（与 Monitor 的存储目录不同）。
2. 右键 Monitor 托盘 → **创建 v2rayN + Monitor 联动启动快捷方式…**，选择实际使用的 `v2rayN.exe`。
3. 桌面将新增 `v2rayN + Monitor.lnk`；如同名文件已存在，会使用新名称而不覆盖。
4. 此后**从这个新快捷方式**启动时，v2rayN 未运行则启动，Monitor 未运行则在托盘后台启动并自动采集。不会为联动启动自动打开浏览器；查看统计仍通过 Monitor 托盘。
5. 移动或替换任一可执行文件、修改 Monitor 采集数据目录后，请核对设置并重新创建快捷方式。启动 v2rayN 需要 UAC 授权时，仍由 Windows 正常弹出；Monitor 不自行提权。

新建快捷方式保留当前 Monitor 的数据目录与账本模式：v1 不附加模式参数，v2 使用 `--scope-ledger`，v3 使用 `--probe-ledger`。之后若受控更改账本模式，请从相应模式的 Monitor 托盘重新创建快捷方式；启动不会自动迁移或降级历史。

联动前必须先在 Monitor 设置中选择正确的 v2rayN 数据根目录。普通便携模式下，该目录应与所选 `v2rayN.exe` 所在目录一致；使用 v2rayN 的 LocalAppData 数据目录模式时允许相应的 `%LOCALAPPDATA%\v2rayN` 根目录。若存在另一个目录的 v2rayN、多个实例、其他 Windows 登录会话中的同名进程，或无法核实已运行进程的程序路径，联动启动会**拒绝假定它们就是同一个实例**并提示检查，不会擅自关闭其他程序。

联动入口先初始化 Monitor 的历史库与采集循环，再请求启动 v2rayN，以减小启动阶段未采集的时间。**首次成功采样仍只建立基线，不能补记此前已经发生但没有可靠基线的流量。** 快速重复点击由互斥锁限制，UAC 长时间未完成时可能提示稍后重试；不要把界面显示“已启动”理解成已经有有效字节样本。

桌面快捷方式创建使用当前 Windows 的 `WScript.Shell` 组件；该组件被组织策略禁用时，创建将失败，但现有 Monitor 采集与开机启动不受影响。快捷方式绑定创建时的程序文件路径，更新便携程序位置后需要重新创建。

**边界：** 本功能不监听任意 `v2rayN.exe` 进程的创建事件。直接使用 v2rayN 原有入口或其开机任务，不会借此唤起未运行的 Monitor。如希望登录 Windows 后始终可采集，继续使用 Monitor 托盘已有的“登录 Windows 时启动”选项。关闭 v2rayN 不会自动退出 Monitor；未能读取核心时保留原有的缺口/未知语义。联动启动不读写 v2rayN 配置，不增加另一套历史账本。
