# 初版预览使用说明

## 1. 准备

目标：Windows x64，v2rayN 7.25.1，Xray，普通单节点。真实 Windows 会话尚待验收，先保留你的原有数据备份，不用于账单或费用结算。CI 便携包包含 .NET 运行时，不需要管理员权限、驱动、WebView2 或常开浏览器。

运行 `V2rayN-Monitor.exe` 后，会出现托盘图标并打开系统浏览器。关闭网页继续采集；选择托盘“退出并停止采集”才停止程序。重复启动同一 Monitor 数据目录不会产生第二个写入进程。

## 2. 连接 v2rayN

1. 在 v2rayN 中自行确认使用 Xray、普通单节点，并开启流量统计或实时速度显示。Monitor 不会代你修改这些设置或重启核心。设置改变后是否需要重新启动核心，以 v2rayN 界面提示为准。
2. 在 Monitor 设置或托盘“选择 v2rayN 数据目录”中，选择包含 `guiConfigs/guiNConfig.json`、`guiConfigs/guiNDB.db` 和 `binConfigs/config.json` 的根目录。便携安装通常是程序目录；启用 `V2RAYN_LOCAL_APPLICATION_DATA_V2=1` 时可能是 `%LOCALAPPDATA%\v2rayN`。
3. 首次成功读取只建立基线，之前已有累计不会全部算作今天。此后生成的流量会按节点写入历史。
4. 托盘打开的是短期会话链接。若页面提示会话过期，从托盘重新打开即可；刷新网页不会重复记账。

## 3. 查看与导出

默认使用首次启动时的系统统计时区，可以在设置中更改。数据库一直保存 UTC，改时区只改变分组方式，不改字节量。日看小时、周/月看日、年看月，也可自定义时间范围和分桶粒度。周从周一开始。

字节值始终为整数；GB/GiB 只是显示单位。记录为 UTC 分钟汇总，跨分钟短采样按比例分配，属于分时近似。单次导出最多 100000 条记录，超过后缩小范围或选择节点。节点名已处理表格公式前缀。

图表空档、采集缺口与“恢复但未分时”有不同含义。后者仅在同一进程/映射身份仍可确认时恢复总量，不放进日期图表。未知归属不计到新节点。历史不会因为接口离线被覆盖。

## 4. CSV 只是可选补充

表头固定为 `node_name,rate,origin_traffic,origin_x_rate,traffic,log_time`。来源填写服务商/账户标识，时间明确选择时区；无时区时间格式为 `yyyy-MM-dd HH:mm:ss`。无法确定的夏令时重复/跳变时间会拒绝导入。

先预览再确认。数值列原始量与计费量各自保存，traffic 只是原始显示文本。每文件最多 4 MB（UTF-8 编码后 4,000,000 bytes）、50,000 条数据记录，不含表头。相同来源的同文件重复导入不双算；不同文件时间范围重叠则拒绝，避免无稳定 ID 时猜测去重。记录时间最小值和最大值不证明完整覆盖。没有设备、IP、上下行字段时就是未知，不能把差额归给某台设备。

CSV 与本机数据分别存储、分别显示，不相加。初版未提供批次撤销；提交前确认来源和时区。

## 5. 故障排查

- 未配置目录：选择 v2rayN 数据根目录，不能只选 `guiConfigs` 子目录。
- 未启用统计/无 metrics：在 v2rayN 自行开启流量统计或实时速度显示，确认有效配置重新生成；端口是动态的，不要写死端口号。
- 无法核对进程/端口：Monitor 保持普通权限。v2rayN 已提升权限时，会尝试只读补足 WMI 缺失的路径和命令行，并核对创建时间；仍无法核实时暂停归属并保留缺口。不要为此给 Monitor 提权。
- Hysteria2：V2free 7.25.1 的 Xray 配置按 `hysteria` 和 transport auth 识别；需与所选节点及进程代次一致。
- AnyTLS：V2free 7.25.1 为该协议选择 sing-box，当前采集器尚未覆盖。不要为接入 Monitor 擅自切换核心或节点。
- 配置正在切换/基线变化：等待 v2rayN 完成切换。旧进程响应不会被归给新配置；正常情况下新核心产生后重新建基线。
- 不支持模式：关闭 TUN/链/策略组等需由你自己决定。Monitor 不自动更改代理路由。
- 没有流量字段：尚未观察到可验证的计数，不等于零。流量产生后仍未出现时检查 Xray 统计设置。
- 写入失败：检查磁盘空间和 Monitor 数据目录权限。不要删除数据库作为第一步，也不要上传真实库或完整配置排错。
- 页面打不开：确认默认浏览器可用，然后从托盘重开。页面关闭不会影响采集。

## 6. 数据与备份

默认 `%LOCALAPPDATA%\V2rayN-Monitor\data`，演示为同级 `demo`。自定义 Monitor 目录通过 `--data-dir`，与 v2rayN 数据目录是两个不同设置。

退出 Monitor 后备份整个 Monitor 数据目录（包含 history.db、provider.db、settings.json 及可能的 SQLite sidecar）。不要在运行中只复制主数据库文件。不要把数据目录放进公开仓库、共享文件夹或自动上传位置。开机启动由托盘菜单显式开关，只修改当前用户的启动项。

便携预览未签名，可能触发 Windows 下载文件提示。自行核对对应提交与 CI SHA256，不要绕过浏览器证书/安全连接警告。正式 Release、签名与实机验收尚未完成。
