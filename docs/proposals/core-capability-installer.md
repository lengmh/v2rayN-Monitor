# 配套核心下载、安装与能力核验提案

状态：**planned，未开始实现**。任务 S5.9，需求见 Issue #34。

处理顺序：先处理 PR #25（联动启动），再处理 PR #30（UI 优化），最后实施本提案。PR #33 为累计审查用途，明确不合并，不属于功能队列。本提案不提前修改安装器、下载器、页面、核心、sidecar 或账本。

## 1. 背景与目标

2026-10-20 已发布 `v0.2.0-preview.2` 的 basic、full、extended 三个独立预发布包，源码基线为 `ee565ace7c122aecce65d048a201892abf3f38d5`。三档使用同一 Monitor，主要区别是配套核心与建议启动模式。

当前需要用户手动下载、核对并安装核心。目标是在 Monitor 设置中提供受控入口：选择 v2rayN，检测现有能力，下载指定兼容组件，校验并准备安装，备份和替换后核验实际生效。三档离线包继续保留；在线增强不要求重新安装另一套 Monitor。

下载、校验和安装准备期间保持当前代理连接。安装需要停止目标核心时，先展示具体影响，由用户安排中断窗口。首版提示用户通过 v2rayN 正常重载服务，不自动结束 v2rayN、强杀核心或重启代理。

## 2. 能力与入口

| 能力 | 界面入口 | 组件与前提 |
|---|---|---|
| 基础版 | 检测现有 Xray | 普通统计使用原 Xray，不为普通统计安装探测核心 |
| 完整版 | 下载／安装 sing-box 统计支持 | 已兼容的 `sing-box-client.exe`、已核实 sidecar 和成员目录、普通多范围模式 |
| 扩展版：sing-box | 启用独立探测统计 | 已有 test.5 摘要匹配时直接复用，按需准备 v3 |
| 扩展版：Xray | 下载／安装 Xray 探测支持 | 精确核验的实验核心、适用标准配置与 v3；普通统计无需替换原 Xray |

档位是能力集合，不是许可证开关。分别展示文件已安装、实际运行版本、接口能力和账本支持；不能根据包名或 EXE 存在就宣称生效。两种核心的探测分别核验，不把单项通过显示为全部扩展可用。

Xray 实验核心基于固定公开上游，与原安装的定制核心不宣称源码或功能完全等价。探测流字节不等同服务商计费，Xray 探测与出站累计可能重叠，不能相加或直接相减。

## 3. 用户流程

1. **检测目标。** 用户选择或确认现有 v2rayN；显示客户端版本、程序／数据／核心目录、运行核心和当前能力。无法唯一核实时显示原因。
2. **下载并校验。** 展示将增加的能力、组件版本、下载大小与许可。用户可取消；完成后进入已校验状态，不触碰安装文件。
3. **准备安装。** 显示旧新版本、精确目标、备份位置、sidecar 差异、账本衔接和是否影响连接。已有兼容核心直接复用。
4. **安装与重载。** 用户确认后，在目标核心停止的前提下备份并替换；目标仍运行时等待。提示用户在 v2rayN 中正常重载，不自行中断代理。
5. **核验生效。** 核对新进程、实际路径、摘要、配置代次、只读统计接口及模式；建立新基线。失败时说明当前处于已下载、待重载还是需恢复。

用户界面保留下载、取消、重试、安装、查看备份和恢复入口。展示有意义的版本、路径和影响，不暴露令牌、完整配置或节点凭据。

### 状态

`未安装 → 下载中 → 已校验 → 等待目标核心停止 → 已安装待重载 → 核验中 → 已生效`

下载失败返回可重试状态，当前安装保持。安装失败分别显示修改了哪些文件、备份是否完整、恢复是否成功。取消下载与取消安装分开处理；不能在已替换部分文件时简单显示已取消。

## 4. 组件发布与信任

### 独立组件包

在线安装分别下载 sing-box 与 Xray 组件，避免下载整套 full／extended。各包包含二进制、版本、架构、固定上游源码、补丁、许可和构建依据；保留对应源码获取方式。现有三档包不变，组件资产在实施阶段另行准备和验证。

兼容清单至少绑定 Monitor 版本范围、Windows x64、已核实客户端构建、核心 SHA256、资产大小、允许文件及能力。文件身份与实际运行身份分别核对。当前 test.5 已含普通统计和探测能力，不因切换档位重复下载或安装。

### 下载边界

- 首版采用随 Monitor 发布的固定兼容记录及精确摘要，下载地址限制为本项目受控 Release；不接收页面传入的任意 URL，不盲目跟随 latest。
- 核验依据不能只是与 EXE 一起下载的未经认证摘要。后续若改为远程更新兼容记录，需另有可信校验方式，不在本提案中预设签名服务。
- 支持当前系统或用户明确选择的下载代理；不为了下载更改系统代理或 v2rayN 路由。限定重定向、超时和大小，不把授权信息转发到非预期主机。
- 先下载到临时文件，完成摘要和内容校验后标记可用。损坏、取消、超时、空间不足或访问拒绝都不修改运行核心。
- 解包仅允许清单内文件，限制展开大小，拒绝路径穿越、绝对路径和链接逃逸。恢复下载可后续按实际需要加入，首版先支持可靠重试。

## 5. 安装目标、备份与恢复

复用已有发现与身份检查，明确区分 v2rayN 程序目录、数据目录和核心目录。便携与 LocalAppData 布局分别核实；多实例、版本未支持、路径不可读或无法确认目标时拒绝安装，不能仅靠进程名或空闲端口建立归属。

目标范围限已核实安装中的配套核心及必要 sidecar。操作前核对解析后的路径、重解析点和实际归属，执行前再次复核。文件变化或目标切换时重新准备，不沿用旧确认。

安装只在目标核心停止后执行。不同核心运行时，若能证明目标文件没有被使用，可继续准备并明确安装影响；不能以当前活跃核心不同为由跳过文件占用检查。目标目录不可写时报告原因，不自动提权。

创建不覆盖旧备份的新备份目录，记录旧文件存在性、摘要、安装计划与实际完成步骤。验证备份可读后再替换，失败按已完成步骤恢复。安装记录不保存订阅、口令或完整配置，不上传本机路径。

恢复的范围是本次替换的核心和 sidecar；不回滚流量账本，不恢复过时的数据库备份以丢弃新增历史。已有备份保留，不自动删除安装前文件或其他版本目录。

## 6. sing-box 统计配置

仅放置 `sing-box-client.exe` 不足以证明统计接入。需核实标准配置中的独立 AnyTLS proxy 锚点、可计量成员及 `monitor-stats.json`。

sidecar 仅配置已核实的数值回环监听和成员 tag。检查端口可用性，成员仅取有效配置中的独立代理出站；不写组、direct、block、重复项或不明 tag，不靠显示名猜身份。

现有 sidecar 先读取、校验和备份。内容冲突时展示必要差异，用户确认本次修改后再写入；不覆盖未知字段，不修改订阅、路由、GUI 数据库或完整生成配置。

有效配置或成员列表变化后，不静默改写 sidecar 并重载。提示需要重新核对，使用同一准备、确认及核验流程；不借此扩展任意配置来源适配。

## 7. 账本与 Monitor 模式

| 现有账本 | 普通统计 | 启用探测时 |
|---|---|---|
| v1 | 保留原入口与数据，升级多范围前单独预检 | 先经明确的受控步骤升级多范围，再准备探测；不直接用 v3 参数打开 |
| v2 | 使用 `--scope-ledger` | 停止写入、持有目录锁、新备份和逐值核验后受控迁至 v3 |
| v3 | 继续 `--probe-ledger`，普通统计照常可用 | 复用既有结构及历史，不重复迁移或降级 |

复用已存在的迁移与 UI 元数据初始化能力。若需要对这些入口做包装，先在隔离副本验证；不得把安装核心与实际迁移混为一次未说明的数据操作。

迁移或更改启动模式前提醒并停止 Monitor 写入，保留原数据目录和实例身份。provider、设置、原历史、游标、缺口与未分时恢复量均需保留；失败不能留下半升级状态。若更新登录启动命令，需明确展示其参数变化，保持用户原有启用状态。

关闭探测或恢复原生核心不降级 v3、不清理探测历史。新核心代次先建立基线，不追记首接前累计，不复用不连续游标。不能新建空目录并显示为历史升级成功。

## 8. 本地接口与实现范围

HTML 负责展示和交互，Windows Host 执行受控下载与文件操作，沿用现有回环监听、会话认证、Host／Origin 检查。新增接口只接受受支持组件和已核实目标的有限标识，不能变成任意路径写入、下载代理或命令执行入口。

组件下载、安装、账本衔接分别记录状态，防止同一目标重复安装。只在存在明确不可信输入和文件修改边界处增加必要校验，不引入通用核心市场、常驻更新服务或插件平台。

以下内容不纳入首版：

- 自动停止或重启 v2rayN／核心、强杀进程、默认管理员运行。
- 后台静默升级任意核心或自动安装 latest。
- TUN、代理链、多实例、任意完整配置来源及其他客户端支持。
- CSV 批次增强、额外 UI 动效、跨设备同步和远端安装。
- 代替 PR #25 的联动启动功能，或并入 PR #30 的布局与动效修改。
