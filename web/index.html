    采集与设置

    设置采集目录和统计时区。

    v2rayN 实例

    选择包含 guiConfigs 和 binConfigs 的数据根目录，通常在程序旁或用户目录。只读采集，不修改配置、重启内核或清零统计。

    按此时区划分日期及解释 CSV 时间，周区间从周一开始；原始时间以 UTC 保存。

    首次连接

    1. 使用兼容的 v2rayN；sing-box 成员统计及两种核心的独立探测计量均需配套核心。
    2. 在 v2rayN 开启流量统计或实时速度显示，并应用配置。
    3. 保存数据根目录，保持 v2rayN 和 Monitor 托盘运行。
    4. 首次采样仅记录当前累计值，之后记录新增流量，不追记接入前的流量。
    Xray 支持已核实的独立代理出站和策略组实际出站。配套扩展可单独记录 sing-box URLTest 与 Xray Observatory 探测；未覆盖流量保持未知。实际范围见下方采集详情。

    配套核心与账本

    只读检查已保存目录中的配套核心文件，不下载、安装或修改配置。

    尚未检查。点击后读取文件摘要及当前状态。

      文件摘要一致仅代表本次文件身份匹配；当前进程、普通统计接口与独立探测分别核验。

      安装与恢复配套核心

      是否有匹配的可下载组件，以本次检查状态为准。准备安装会先下载及预检，满足条件后打开 Host 原生确认窗口，显示确切目标、备份与连接风险；确认前不改安装文件，不会自动停止核心。Xray 扩展仅供可选探测计量，普通统计无需替换核心。

      操作 ID 支持 32 位十六进制或标准带连字符 GUID。恢复仅处理所选组件及该操作 ID 对应的核心文件，不改账本。仍需在 Host 原生窗口最终确认；完成后由你手动重载 v2rayN。

      尚未发起安装或恢复。

      sing-box 统计配置（sidecar）：先保持目标核心运行，核实当前进程与配置；计划最多保留 10 分钟。再由你自行停止目标核心，打开写入或恢复的原生确认窗口。此处不会停止核心、自动重载或改账本；恢复使用上方操作 ID，完成后需重新准备下一次计划。

      尚未准备统计配置。

      手动重载后，可只读核验当前运行核心与普通统计接口（reset=false），不写账本。普通统计可读不代表独立探测计数可用。

      尚未核验运行核心。

      账本升级请使用 Monitor 托盘菜单「离线升级账本…」：仅退出 Monitor、保持代理运行，再经第二次原生确认执行单步升级。此页不提供账本迁移接口；不会自动重启 Monitor 或修改启动项。

      导入记录

      按来源导入服务商 CSV。

      服务商原始量、计费量与本机流量分别保存，不相加。文件未提供的方向、设备和 IP 为未知。

      导入 CSV

      默认关闭；仅在导入成功后由你点击另存，保留原字节及 BOM，不随撤销删除。

      格式与去重说明

      仅支持六列：node_name, rate, origin_traffic, origin_x_rate, traffic, log_time。文件仅发送至本机。

      每文件最多 4 MB、50,000 条数据记录（不含表头）。

      同一来源按导出快照去重，保留相同行的出现次数。同名同时间的计费字段变化若无法确认，会提示冲突，不覆盖旧记录。
